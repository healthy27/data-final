# 방법론과 모델 카드

## 사용 목적과 현재 상태

기업의 전년도 재무·직원 정보와 다음 해 적자 여부 사이의 관계를 탐색하는 교육·포트폴리오 프로젝트입니다.
실제 배포, 투자 추천, 고용 의사결정에 사용하는 모델이 아닙니다.
이 문서는 새로 수집할 다년도 DART 자료의 설계입니다. 합성 데이터로 실행 경로를 검증했습니다.
제공된 2021·2022년 실제 파일은 메타데이터가 부족해 별도 경로로 분석했습니다.
[제공 자료의 평가 설계](legacy_methodology.md)와 [실제 결과](../reports/legacy/report.md)를 참고하세요.

## 관측 단위와 타깃

- 한 행은 DART 고유번호 × 사업연도입니다. 이름은 표시용이며 결합 키가 아닙니다.
- 연간 사업보고서(11011), 별도/개별 재무제표(OFS)를 고정합니다.
- 입력 연도 t의 특징으로 t+1년 순이익이 음수인지를 분류합니다. 적자=1, 흑자=0.
- 타깃 결측과 순이익 0은 제외합니다. 0을 어떻게 다룰지는 사전에 명시한 선택이며, 실데이터에서는 별도 민감도 분석이 필요합니다.
- 직원수 결측은 남기며, 학습 fold 내 중앙값 대체와 결측 표시자로 처리합니다.
- 금융업처럼 매출과 부채의 경제적 의미가 다른 업종은 별도 모집단으로 분석하는 것을 권장합니다.

## 피처 설계

허용 목록에 있는 7개 변수만 사용합니다. 기업코드·이름·미래 손익은 X에 들어가지 않습니다.
재무 변수는 log(1+자산), 부채/자산, 영업이익/매출, 순이익/매출, 매출 증가율입니다.
고용 변수는 log(1+직원수), 직원수 증가율입니다.
성장률의 분모가 0이거나 전년 자료가 없으면 결측으로 유지합니다. 중간 연도가 빠졌을 때 2년 차이를 1년 성장률로 계산하지 않습니다.
전년도 순이익은 예측 시점에 알려져 있다는 가정 아래 입력으로 허용하지만, 같은 해 또는 다음 해 순이익은 허용하지 않습니다.

## 평가 절차

예제의 타깃 연도는 2019–2024년입니다.

| 검증 타깃 연도 | 학습 타깃 연도 |
| --- | --- |
| 2021 | 2019–2020 |
| 2022 | 2019–2021 |
| 2023 | 2019–2022 |
| 최종 평가 2024 | 2019–2023 |

검증 fold에 두 클래스가 없으면 그 fold를 제외하고, 유효 fold가 없으면 실패합니다.
클래스 사전확률 기준 모델, 로지스틱 회귀, 작은 히스토그램 그래디언트 부스팅을 비교합니다.
각 모델에 재무 변수만 넣은 경우와 고용 변수를 추가한 경우를 비교합니다. 기준 모델은 중복 비교하지 않습니다.
평균 검증 Average Precision(AP)이 가장 높은 조합을 선택합니다. 최종 평가 연도는 선택에 사용하지 않습니다.
임계값은 0.5로 고정하고 AP·ROC-AUC·적자 precision/recall/F1·balanced accuracy·Brier score를 기록합니다.
최종 모델은 과거 타깃 연도 전체로 다시 학습하며, 전년 손익 상태 유지 기준과 학습 적자비율 기준도 함께 평가합니다.

고용 변수의 추가 가치는 **같은 모델의 두 피처 구성을 이전 연도 검증 결과에서 비교**합니다.
가장 좋은 두 모델의 점수 차이만 보고 고용 효과라고 해석하지 않습니다. 예제 데이터는 고용 효과를 입증하지 않습니다.

## 시간 누수에 대한 정확한 범위

이 구현은 **사업연도 순서**와 학습 전처리 누수를 통제합니다. 그러나 공시가 실제로 이용 가능했던 시점까지 복원하지는 않습니다.
예를 들어 2023년 사업보고서는 통상 2024년에 공개됩니다. 따라서 2023년 재무정보를 2024년 초부터 알았다고 가정하면 안 됩니다.
정정공시가 반영된 현재 스냅샷은 당시의 정보 집합과도 다를 수 있습니다.
접수번호와 원본 응답을 보존하지만 이를 자동으로 과거 스냅샷으로 복원하는 것은 아닙니다.

실전 예측 실험으로 확장하려면 다음이 필요합니다.

1. 예측일을 명시하고, 그 시점에 공개된 원본 보고서만 사용합니다.
2. 학습 타깃의 공개일도 예측일 이전인지 확인합니다.
3. 정정공시의 각 버전을 별도 보관합니다.
4. 당시의 상장 기업 모집단과 상장폐지 기업을 포함해 생존편향을 점검합니다.

동일 기업이 여러 연도에 반복됩니다. 이 평가는 관측된 기업군의 미래 연도 일반화에 가깝고, 새로운 기업 일반화를 보장하지 않습니다.
그 질문에는 기업 단위 분리 검증이 별도로 필요합니다.

## 통계·설명 가능성

직원수 변화율과 순이익 변화/전기 자산의 Pearson 및 Spearman 상관계수를 연도별로 기록합니다.
다년도 관측을 독립 표본처럼 풀링하지 않습니다. 업종·규모·경기 요인 통제나 인과 추론은 구현 범위 밖입니다.
Permutation importance는 최종 평가 데이터에서 AP 변화로 계산하며, 모델 선택에 재사용하지 않습니다.
상관된 변수는 중요도를 나눠 가질 수 있고, 중요도는 인과 효과가 아닙니다.

95% 구간은 단일 테스트 연도에서 클래스별 기업 복원추출을 300회 하는 percentile bootstrap입니다.
학습 모델은 고정되며 학습 표본 변화·연도 간 충격·기업집단 의존성에 대한 불확실성을 모두 반영하지 않습니다.
원래의 VIF 단계는 제거했습니다. 수백 개 회계 계정의 선형 종속을 계산하는 것보다, 작은 피처 집합과 유효한 평가 설계가 이 목적에 더 적합합니다.

## 의도적으로 추가하지 않은 것

- LLM/RAG: 현재의 정형 재무 분류 질문에 필요한 기능이 아닙니다.
- 복잡한 MLOps 서버: 이 규모에서는 Git·lockfile·JSON 실험 기록·CI로 재현성을 확인할 수 있습니다.
- SHAP: 먼저 검증 설계와 데이터 품질을 고정하고 기본 중요도 해석을 제공합니다.
- 실시간 대시보드: 데이터 정의가 검증되기 전에 화면만 만드는 것을 피했습니다.
- 과도한 하이퍼파라미터 탐색: 작은 표본에서 검증셋에 과적합할 기회를 줄였습니다.

이는 모든 최신 데이터 프로젝트에 같은 기술이 필요하다는 주장이 아니라, 이 문제에 맞춘 설계 선택입니다.

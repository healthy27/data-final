# 제공된 2개 연도 자료의 평가 설계

상세한 선택 근거와 결과는 [사례 연구](case_study.md)에 있습니다.
이 문서는 재현에 필요한 고정된 실험 조건을 기록합니다.

## 데이터 준비

- 원본 5개 파일의 파일명과 SHA-256을 `source_audit.json`에 기록.
- kospi100·kosdaq100 단순 연결과 merge (2)의 일치 확인.
- 원본 계정명에서 공백·열거 번호만 제거. 명시된 동의어만 허용.
- 동일한 후보 값은 하나로 처리, 값 충돌은 결측. 합산·첫 행 선택 금지.
- 2022년 순이익 결측·0 제외. 2021년 재무 피처 4개 중 최소 2개 관측 필요.
- 직원수는 최종 CSV와 요약 Excel의 서로 다른 값이 있으면 결측으로 유지.
- 기업명은 현재 파일에서의 식별 키이며 DART 고유번호가 검증됐다고 간주하지 않음.
- 통화·연결/별도·기간·공시 시점은 unknown. 별도 새 DART 계약으로 강제 변환하지 않음.

## 피처와 타깃

타깃: 2022년 제공 순이익 < 0.
재무 피처: 2021년 순이익/자산, 순이익/매출, 영업이익/매출, 부채/자산.
고용 피처: log(1+2021년 직원수). 2022년 값과 직원수 증가율은 X에 포함하지 않음.
분모가 양수가 아니면 비율은 결측. 원시 금액의 기업 간 크기는 사용하지 않음.
비율의 단위 불변성은 같은 회사의 분자·분모가 같은 통화·범위라는 가정에 한정됨.

## 모델·평가

- 비교 모델: C=1 로지스틱, max_iter=80·max_leaf_nodes=7·min_samples_leaf=15·L2=2 부스팅.
- 각 모델에 재무만 / 재무+직원수의 2개 피처 구성.
- 5-fold StratifiedKFold, shuffle=True, seeds=42,43,44,45,46.
- 내부 선택: 외부 학습셋에서 3-fold AP 평균을 최대화. 동점이면 정의 순서로 결정.
- 사전 정의한 모델의 외부 점수도 기록하되 가장 높은 행을 골라 별도 확정 성능으로 주장하지 않음.
- 결측 대체·결측 표시자·스케일러는 각 학습 Pipeline에서만 fit.
- 기준: 외부 학습 적자 비율, 전년 적자 여부. 전년 순이익 결측일 때만 학습 비율 대체.
- 적자=1, 임계값 0.5 고정. 임계값·하이퍼파라미터를 결과 확인 후 튜닝하지 않음.
- repeat별 전체 OOF 점수를 계산한 뒤 5회 평균·최소·최대 보고.
- 반복 최소·최대는 분할 민감도이며 신뢰구간이 아님.

층화 fold의 학습 클래스 비율은 조금씩 다를 수 있습니다.
따라서 민감도 표본의 class_prior OOF 점수는 상수 예측의 이론값과 정확히 같지 않을 수 있습니다.

## 비교와 민감도

직원수 추가 가치는 동일한 로지스틱·표본·분할의 AP 차이를 우선 보고합니다.
부스팅의 같은 비교도 표에 보존합니다.
두 연도 직원수 쌍이 3개 이상 기업에 반복되면 검토 플래그를 표시하고 제외 표본에서 고정 로지스틱 비교를 반복합니다.
플래그는 사후 민감도 분석에만 쓰며 미래 예측 입력으로 사용하지 않습니다.

상관분석은 2021→2022 직원수 변화율과 순이익 변화/2021 자산을 사용합니다.
완전 관측 쌍의 Pearson·Spearman 통계와 탐색 p값을 보고합니다.
업종 통제·다중검정 교정·기업집단 의존성 처리를 수행한 확증 분석이 아닙니다.

## 검증하지 못한 범위

한 번의 연도 전환밖에 없어 미래 연도 외부 검증을 수행할 수 없습니다.
자료 수집 코드에 있었던 전년도 fallback, 공시 정정, 직원수 범위를 제공 파일만으로 완전히 복원할 수 없습니다.
자료의 행별 실제 통화·연결 기준과 기업 정체성을 공시 원문으로 확인하기 전까지 탐색 결과로 유지합니다.
관련 기업집단·업종·선정 편향이 남습니다. 개별 기업의 실제 손익을 이 파일만으로 확정하는 목적이 아닙니다.

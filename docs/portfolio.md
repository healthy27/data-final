# 포트폴리오에 쓸 내용과 면접 답변

상세한 근거·방법·장단점은 [전체 사례 연구](case_study.md)에 있습니다.
아래 문안은 그대로 활용할 수 있는 초안입니다. 본인이 구현을 읽고 검증한 범위에 맞게 조정하세요.

## 추천 제목

**기업 재무·고용 데이터의 품질 감사와 다음 해 적자 분류 검증**

부제: 결측 대체·계정 매핑 오류를 추적하고 단순 기준과 비교한 재현 가능한 분석 프로젝트

## 프로젝트 한 문단 소개

기업 재무·직원수를 활용한 수업 프로젝트를 개선하면서 원본 Excel·CSV 5개를 대조했다.
계정 구분 없는 중앙값 대체 1,134개, 동일 재무 행 33개 중복, 잘못된 총계 매핑 96행을 확인했다.
관측값을 다시 추출해 125개 기업의 2021년 재무 비율·직원수로 2022년 적자를 분류했다.
반복 nested CV와 단순 기준 비교 결과, 복잡한 모델의 일관된 우위와 직원수 추가의 안정적인 개선을 확인하지 못했다.
오류의 영향, 선택한 검증 방식, 결과의 한계를 재실행 가능한 코드와 감사 기록으로 남겼다.

## 이력서에 쓸 3개 항목

- 제공 재무·직원수 파일 5개를 대조해 결측 대체 1,134개와 잘못된 총계 매핑 96행을 정량화하고, 계정 허용 목록·원본 행 추적으로 분석 데이터를 재구성.
- 125개 기업의 단일 연도 전환에서 학습 fold 내부 전처리, 5×5 외부 검증·3-fold 내부 선택, 단순 기준 및 직원수 ablation으로 모델의 추가 가치를 평가.
- 전년 적자 유지 기준의 정확도 85.60%·적자 재현율 64.0%를 확인하고, 직원수 추가의 로지스틱 AP 변화가 평균 +0.0011에 그쳐 안정적 개선을 주장하지 않음.

직접 수집한 자료·원래 작성한 코드·AI 도구와 함께 개선한 코드를 구분해서 역할을 설명한다.
자신이 수행하지 않은 실데이터 수집이나 원문 대조를 했다고 표현하지 않는다.

## 포트폴리오 페이지 구성

1. **문제:** 기존 95.24% 정확도가 미래 손익 예측을 의미하는지 점검했다.
2. **진단:** 원본 대조로 결측 대체·계정 의미 변경·중복·타깃 손상 사례를 확인했다.
3. **선택:** 원본 추출, 제한된 비율형 변수, 기업 간 nested CV를 자료의 규모·연도 수에 맞춰 채택했다.
4. **비교:** 단순 기준·로지스틱·부스팅, 직원수 추가 전후, 반복 직원수 쌍 제외 표본을 같은 조건에서 비교했다.
5. **결과:** 모델의 실익이 지표마다 달랐고 직원수 추가 효과가 불안정했다.
6. **한계:** 통화·연결 범위·실제 수집 연도·공시 시점 미확인과 한 번의 연도 전환이라는 제약을 기록했다.
7. **재현:** 입력·제외 사유·fold·OOF 예측·실험 결과·자동 테스트 링크를 제시한다.

첫 화면에는 `reports/legacy/comparison.png`와 작은 성능표를 사용한다.
그 다음 원본 매핑 오류 사례와 처리 전후 흐름을 넣는다.
ROC 곡선 하나만 크게 보여주기보다 왜 그 성능을 평가하게 됐는지 설명하는 구성이 적합하다.

## 면접 질문과 답변 예시

**왜 XGBoost를 더 튜닝하지 않았나요?**

초기 문제는 파라미터보다 입력과 정답 생성에 있었습니다.
원본을 보니 서로 다른 계정을 같은 이름으로 바꾸고 결측 정답을 양수로 채우는 처리가 있었습니다.
이를 먼저 고친 뒤 작은 선형 모델과 부스팅을 단순 기준과 비교했습니다.
표본이 적어 과도한 탐색보다 선택·평가 분리와 한계를 명확히 하는 것을 우선했습니다.

**왜 시간순 검증을 하지 않았나요?**

제공 자료에는 2021·2022년만 있어 검증할 연도 전환이 하나뿐이었습니다.
이를 여러 연도처럼 나누지 않고 2021년 입력·2022년 타깃의 기업 간 검증을 했습니다.
미래 연도 성능을 측정한 결과라고 주장하지 않습니다.
다년도 DART 자료를 확보했을 때 쓸 순차 검증 경로는 별도로 구현했습니다.

**nested CV가 왜 필요했나요?**

모델과 피처 구성을 선택하는 데이터와 그 선택 결과를 평가하는 데이터를 나누기 위해서입니다.
외부 학습 기업 안에서 3-fold로 AP가 좋은 조합을 고르고 외부 평가 기업에 적용했습니다.
단점은 계산량과 작은 fold의 변동성입니다. 반복 범위를 신뢰구간으로 해석하지 않았습니다.

**왜 정확도 대신 AP도 봤나요?**

적자가 20%라 모두 흑자라고 해도 정확도 80%였습니다.
적자 기업을 높은 위험 순위에 놓는지를 AP로 보고, 실제 경고 기준에서 얼마나 놓치는지는 재현율로 봤습니다.
내부 선택 절차는 AP가 0.5708로 전년 상태 기준 0.4816보다 높았지만,
임계값 0.5의 적자 재현율은 38.4%로 기준 64.0%보다 낮았습니다.
따라서 모든 면에서 개선했다고 말하지 않았습니다.

**직원수는 도움이 됐나요?**

같은 로지스틱과 같은 분할에서 AP가 평균 +0.0011 변했고 분할별로 개선·악화가 섞였습니다.
반복 직원수 쌍을 제외한 표본에서는 AP가 낮아졌습니다.
이 자료에서는 안정적인 추가 가치가 확인되지 않았습니다.
직원수 효과가 없다고 입증한 것은 아니며 원본 직원수 범위·대체 여부를 검증할 필요가 있습니다.

**가장 중요한 개선은 무엇인가요?**

모델 점수 이전에 정답을 검증한 것입니다.
제공 원본에서 적자인 한 기업이 중앙값 대체와 합산 후 흑자로 바뀐 사례를 찾았습니다.
그 후 결측 타깃 제외, 계정 의미에 따른 추출, 원본 행 추적을 코드와 테스트에 반영했습니다.

**배포하지 않은 이유는 무엇인가요?**

원본 통화·연결 범위·공시 시점이 확인되지 않았고 미래 연도 검증도 없었습니다.
이 상태에서 서비스 화면을 만드는 것보다 재현 가능한 감사와 실험 결과를 남기는 것이 현재 병목에 맞았습니다.
추가 데이터와 사용 목적을 확정한 뒤 비용 기반 임계값·원문 대조·외부 검증을 선행할 계획입니다.

## 표현할 수 있는 성과와 피해야 할 표현

| 표현 가능 | 현재 근거로 뒷받침하지 못하는 표현 |
| --- | --- |
| 전처리 오류를 원본 대조로 정량화했다 | 실제 공시 원문까지 모두 검증했다 |
| 125개 기업에 기업 간 교차검증을 적용했다 | 여러 미래 연도 예측 성능을 입증했다 |
| 단순 기준의 강점과 모델의 지표별 차이를 확인했다 | 기존보다 예측력이 확실히 향상됐다 |

| 실행 기록·테스트·CI를 만들었다 | 배포해 실무 효과나 투자 성과를 달성했다 |
